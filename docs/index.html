Setup

Up and running in 5 minutes

You need Node.js 18+ and a Canvas account. There's nothing to download yourself: your AI app fetches the server with npx.

Create a Canvas token

In Canvas, go to Account → Settings → Approved Integrations → + New Access Token. Copy it right away, because Canvas only shows it once.

Add it to your AI app

Open your app's MCP config file (usually under Settings → Developer or MCP servers) and add this entry with your token and school address:

{
  "mcpServers": {
    "canvas": {
      "command": "npx",
      "args": ["-y", "canvas-lms-mcp-local"],
      "env": {
        "CANVAS_API_TOKEN": "your_token_here",
        "CANVAS_BASE_URL": "https://yourschool.instructure.com"
      }
    }
  }
}

Then fully quit the app and reopen it. On Windows, use the tray icon → Quit; on macOS, press ⌘Q.

npx -y canvas-lms-mcp-local

Register this command as a stdio MCP server named canvas, with CANVAS_API_TOKEN and CANVAS_BASE_URL set in its environment.
