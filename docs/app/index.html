FAQ

Questions

Is my Canvas token safe?

The app only sends your token to your own school's Canvas, to check that it works, and saves it on your computer in the settings the server uses. There's no tracking or analytics. The servers it installs are open source on GitHub.

Windows says "Windows protected your PC". Is that normal?

Yes. The app isn't code-signed yet, so Windows doesn't recognize it. Click More info, then Run anyway.

Does it work on a Mac?

Not yet. On a Mac, follow the README for the Local or Remote edition.

Which AI apps does it set up?

Claude Desktop and the ChatGPT desktop app for the Local Edition. For the Remote Edition, Claude on the web, desktop and phone, and the ChatGPT desktop app.

How do I remove it again?

Open Auto remove in the app. It's free. It takes Canvas out of Claude Desktop or the ChatGPT app, or stops and uninstalls the Remote server, and backs up each settings file first.

Is this made by Instructure, Anthropic or OpenAI?

No. It's an independent project that works with Canvas, Claude and ChatGPT.

I'm stuck. Where do I get help?

The app's Support tab has fixes for common problems and a button that copies your setup info with secrets hidden. You can also email fireiscoolsolo@gmail.com or open an issue on GitHub.
